# Arquitectura de experiencia

## 1. Navegación principal

- Inicio
- Comprar
- Descubrir
- Colecciones
- Sobre nosotros
- Ayuda
- Buscar
- Cuenta
- Carrito

La distinción **Comprar / Descubrir** debe ser explícita.

## 2. Flujo rápido

Inicio → Comprar → Categoría → Producto → Carrito → Checkout

Objetivo: minimizar fricción.

Componentes clave:

- Filtros por mascota, necesidad, tamaño, precio y uso.
- Tarjetas limpias.
- Información logística visible.
- Compra rápida.
- Favoritos.
- Comparador opcional.

## 3. Flujo curioso

Inicio → Descubrir → Historia / Guía / Edición → Producto contextual → Compra

Objetivo: aumentar tiempo de calidad, confianza y valor percibido.

Tipos de contenido:

- Historias.
- Guías.
- Comparativas.
- Selecciones.
- Ediciones temáticas.
- Casos reales.
- Cuidados y bienestar.
- Viajes.
- Descanso.
- Alimentación.
- Juego y estimulación.

## 4. Página de producto de doble velocidad

### Zona 1 — Resolución inmediata

Debe incluir:

- Imagen principal.
- Nombre.
- Beneficio principal.
- Precio.
- Variantes.
- Tamaño.
- Entrega.
- Devolución.
- CTA.
- Elementos de confianza.

### Zona 2 — Experiencia OVL

Comienza después de la compra rápida.

Puede incluir:

- Escena emocional.
- Narrativa de uso.
- Animación o secuencia visual.
- Anatomía del producto.
- Materiales.
- Prueba de uso.
- Historias de clientes.
- Preguntas frecuentes.
- Productos complementarios por contexto.

## 5. Magazine

El magazine no es un blog separado. Es una capa comercial editorial.

Cada pieza debe contener:

1. Una tensión o necesidad.
2. Una historia.
3. Conocimiento útil.
4. Productos integrados con contexto.
5. Una acción clara.

Ejemplo:

**Viajar sin ansiedad**

- Preparación emocional.
- Seguridad en el trayecto.
- Cómo elegir transportadora.
- Checklist.
- Producto principal.
- Accesorios complementarios.
- Historia real.
- Compra del kit.

## 6. Tipos de landing

- Landing de campaña.
- Landing por problema.
- Landing por estilo de vida.
- Landing por especie.
- Landing por estación.
- Landing editorial.
- Landing de colección.

## 7. Estados esenciales

- Carga.
- Sin resultados.
- Producto agotado.
- Variante no disponible.
- Error de conexión.
- Carrito vacío.
- Confirmación de agregado.
- Recomendación contextual.
- Contenido editorial relacionado.

## 8. Accesibilidad

- Contraste AA.
- Navegación por teclado.
- Texto alternativo.
- Animaciones reducibles.
- Etiquetas claras.
- Tamaños táctiles adecuados.
- No depender exclusivamente del color.
