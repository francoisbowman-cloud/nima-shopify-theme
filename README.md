# OVL × PetDrop — Paquete maestro

Este paquete documenta e implementa la visión de una tienda de bienestar para mascotas con dos modos de experiencia:

1. **Comprar** — experiencia funcional, rápida y orientada a conversión.
2. **Descubrir** — experiencia editorial, narrativa y visual gobernada por OVL.

OVL significa **Omni Visual Language**: un sistema de inteligencia visual y narrativa capaz de interpretar productos, detectar la emoción dominante, definir dirección de arte, producir contenido coherente y adaptar cada historia a múltiples canales.

## Cómo abrir el prototipo

Abre `prototype/index.html` en un navegador moderno. No requiere servidor.

## Principio rector

**OVL no decora páginas. Diseña significado, percepción y deseo alrededor de cada producto.**
